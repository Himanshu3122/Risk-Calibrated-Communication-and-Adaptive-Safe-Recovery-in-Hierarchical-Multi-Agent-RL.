# Code of Conduct

We want this project to be a respectful, harassment-free place for everyone, regardless of
background or identity.

## Expected behavior

- Be considerate and constructive in issues, reviews, and discussions.
- Critique ideas and code, not people.
- Credit others' work, including prior research the code builds on.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, publishing others' private information,
and sustained disruption.

## Enforcement

Report concerns privately to the maintainer (see `SECURITY.md` for the contact route). Maintainers
may remove contributions or block participants who violate this code.

This policy is adapted in spirit from the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
